## 2. PR body

**What**: bounded reading pipeline + unified discovery surface for the
`fa` harness (plan: `worklogs/implementation-plans/s12.7-read-budget-framing-guard.md`,
records §§10–22).

**Why**: unbounded reads and a sprawling 12-param/4-mode search surface
burned context budget and taught the model stale modes; the read chain is
now budgeted (32,768B), framed (head/tail frames with artifact handoff),
guarded (repeat/ping-pong denial with scoped terminality), and discovery
is a ladder: files → outline → matches → fs_read_file.

**Surface change (model-visible)**:
- `fs_search`: 3 modes × 6 params (§A6 v7). Removed: order, include_tests,
  glob, case_sensitive, max_file_size, context_lines (all accepted-but-
  ignored + warning); regions/counts modes → steering errors.
- `fs_read_file`/`fs_run_bash`: oversize results framed + artifact_id
  handoff; descriptions tell the truth.
- Prompt-prefix risk (RK1) reviewed in-plan; description diffs quoted.

**Review trail**: two adversarial passes (R20 §17, R25 §20, R26 §21) —
all findings fixed in-round with pins; no unplanned capability loss
(probe-verified, incl. subagent relevance selection).

**Verification**: see commit message + §23. Live-host e2e: the command
sheet below (also §§10–12, 18, 19, 22).
