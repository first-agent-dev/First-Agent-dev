## 0. Executive intent

**G1 — Framing law.** No tool result is ever silently truncated: every cut carries totals,
position, and the exact next call (`fs_read_file` three-tier frame, run_bash tail frame,
fs_search counts/trailers). *Every l2 failure mode becomes a one-turn recovery.*
**G2 — Guard protects progress, not just tokens.** Detector 2 (distinct-window path counting,
the proven killer of correct work — kimi evidence) is removed; identical-repeat stays; a
period-2 ping-pong detector (F1, operator-accepted; *preventive — field-driven, no FA transcript
shows A-B-A-B yet*) closes the oscillation hole; **warn rounds and PauseGuard semantics are
unchanged**; only a LoopGuard circuit-breaker trip terminates the session in-band with a
structured reason — never a zombie `run_stopped`.
**G3 — Artifacts are followable.** `ArtifactStore.get` + `read_file(artifact_id=…)` make
`[artifact: id]` a pointer, not a dead end (E11).
**G4 — fs_search carries the discovery ladder.** 3 modes (`files`/`matches`/`outline`), 8
params, glob-aware `path`, size-annotated `files` rows, ast-based outline (py symbols + md
ATX/§ sections), leniency ruleset — the model sees the whole picture and picks full read,
window, or symbol range deliberately.
**G5 — One budget, one offload path.** `DEFAULT_TOOL_CONTEXT_BYTES = 32_768` ceiling; offload
is elision-tied at the projection chokepoint only; state.py's threshold-8000 duplicate path is
deleted; events stay audit-complete (full raw inline — superset of model-visible, RD-1).

**Non-goals (explicit):** B6c storage unification/GC/ADR-7 rewrite (backlog); fuzzy query
matching (Q1); tree-sitter/Aider repo-map/token-based or window-scaled budgets; new CLI verbs;
subagent comprehension tier (`subagent_spawning_enabled` stays False); any models.yaml change.
**Minimal mechanism:** one new small module (`tools/outline.py`, ast + md folders reusing
structural_index node semantics); everything else is edits at existing seams (elide= adapters,
projection constants, guard detectors, fs_search mode table). No new dependencies.
**Proof sketch:** C1 live-path via `drive_session` (mocked provider) for guard/offload/framing
producers; registry-dispatch C1 for tool modes; C3 for path-escape/leniency boundaries; C4
mutation on guard + frame + folder; C3-live = pinned-model re-runs l2→l3→l4 (operator-side).
